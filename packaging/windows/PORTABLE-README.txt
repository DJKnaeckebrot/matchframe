Matchframe Portable

1. Run Matchframe.exe
2. Open Setup in the dashboard
3. Install or update the CS2 integration
4. Restart CS2
5. Add the displayed Overlay URL as an OBS Browser Source at 1920x1080

Data for this portable edition is stored in ./data next to Matchframe.exe.
Logs are written to ./logs/matchframe.log.

Dashboard: http://127.0.0.1:3131/
Overlay:   http://127.0.0.1:3131/overlay

Pass --no-browser if you do not want the dashboard to open automatically.
